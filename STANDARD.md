# The Jetty Standard

This is the promise behind the apps I build for OpenJetty. Before I open an app's source here, it has to meet every point on this page. If an app stops meeting one, I fix it or I take it down.

A partner project listed on OpenJetty is looked after by its own maintainers, in its own repo, under its own license. Its listing says so.

## 1. Finished

It works when you open it. It is not a demo, a starter, or a half-built idea. You can set it up and use it for real work.

## 2. Tested by hand

I run every app myself against a written test before it is listed. The written test ships with the app, so you can follow the same steps and see the same results.

There are automated tests too. They do not replace a person using the app.

## 3. Known issues listed, honestly

Every app ships with a list of what is broken or missing. It sits next to the code, in plain words. If I know about a problem, it is on the list.

## 4. One-command setup

One command starts the app. You bring only your own keys for any outside service the app uses. I test the setup again on each release.

## 5. MIT forever

Every app I build is MIT licensed. You can use it, change it, and sell what you build on it. That does not change later.

## 6. Made-up demo data

The demo data that ships with an app is made up. It never holds real records of real people or real companies.

## 7. A security note

Every app has a security note. It says how to report a problem privately and what to expect after you do.

## 8. A named maintainer

Every app names the person who looks after it. You know who to ask.
